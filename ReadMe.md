
Gen-Z Tutor Chatbot 🤖

A beginner Python chatbot built using ChatterBot.

It can answer basic questions about Python and Physics using custom training data.

Technologies:

    Python

    ChatterBot

    spaCy

    SQLite

    Regular Expressions

Run:
python trainer.py
python bot.py

This project helped me learn chatbot training, text cleaning and response matching.

Note: This is a rule-based/retrieval-based chatbot, not a generative AI model.
